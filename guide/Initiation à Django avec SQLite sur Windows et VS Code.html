Initiation à Django avec SQLite sur Windows et VS Code

Par NZANZU ASINGYA Dieu-merci

Objectif : Comprendre l’installation, la configuration et la création d’une mini‑application Django avec base SQLite, en environnement Windows + VS Code, avec gestion du versionning via GitHub.

📝 Développement

🎯 Objectif du module

Ce module vise à :

  • Installer Python et pip sur Windows
  • Configurer VS Code avec un environnement virtuel (venv)
  • Créer un projet Django et une application
  • Gérer la base de données SQLite
  • Utiliser l’interface d’administration
  • Mettre en place le versionning avec GitHub
  • Identifier les difficultés rencontrées et leurs solutions

📂 Procédure pas à pas

1. Installation de Python et pip

Téléchargez Python depuis python.org. Pendant l’installation :

  • Cocher “Add Python to PATH” pour que Python soit reconnu dans le terminal.
  • Vérifier que pip est inclus (gestionnaire de paquets).
python --version
pip --version

2. Création d’un environnement virtuel

Un venv permet d’isoler les dépendances de chaque projet.

py -m venv venv
venv\Scripts\activate
👉 Dans VS Code, sélectionnez l’interpréteur venv\Scripts\python.exe.

3. Installation de Django

pip install django
py -m django --version

4. Création du projet

django-admin startproject mysite
cd mysite

5. Création d’une application

py manage.py startapp blog

6. Définition d’un modèle

Un modèle définit la structure des données.

class Article(models.Model):
    title = models.CharField(max_length=200)
    content = models.TextField()
    pub_date = models.DateField()

7. Migration de la base SQLite

Les migrations créent les tables dans la base.

py manage.py makemigrations
py manage.py migrate
👉 Fichier db.sqlite3 créé.

8. Interface d’administration

Créer un superuser pour accéder à l’admin :

py manage.py createsuperuser

Ajouter le modèle dans blog/admin.py :

from django.contrib import admin
from .models import Article
admin.site.register(Article)

Relancer le serveur :

py manage.py runserver

Accéder à http://127.0.0.1:8000/admin.

9. Ajout d’une deuxième application

py manage.py startapp shop
👉 Nouvelle table shop_product dans db.sqlite3.

📚 Exercices pratiques

  • Créer un modèle Article et l’ajouter à l’admin
  • Créer un modèle Product et l’ajouter à l’admin
  • Vérifier les tables dans db.sqlite3
  • Tester l’ajout d’articles et de produits via /admin

⚠️ Difficultés rencontrées et solutions

  • Erreur Pylance (Import django.db) → Sélectionner le bon interpréteur (venv)
  • Erreur “manage.py introuvable” → Se placer dans le dossier mysite
  • Mot de passe invisible lors du superuser → Normal, continuer la saisie
  • Conflit Python global → Supprimer ou ignorer le global, travailler uniquement avec venv
  • Serveur bloquant le terminal → Arrêter avec Ctrl + C ou ouvrir un deuxième terminal

git push -u origin main

Conclusion

Ce guide couvre l’installation, la configuration, la gestion de la base SQLite, l’utilisation de l’admin Django et la mise en place de GitHub pour le versionning. Tu es prêt pour enrichir ton projet avec des relations, formulaires, API et déploiement.
